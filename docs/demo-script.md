# Silvia 90-second demo

## Before recording

- Open <https://silvia-dec7df73.base44.app>.
- Sign in with Google.
- Confirm that live checkout remains disabled.
- Start with no confirmation token in the current browser session.
- Keep the Base44 dashboard open in a second tab if you want to show the fresh
  App ID and deployed functions.

## Script

### 0:00 to 0:12

Show the Silvia sign-in screen.

Say:

> My grandmother should not need to learn five delivery screens to ask for
> dinner. Silvia turns the flow into a conversation she already understands.

### 0:12 to 0:27

Sign in and show the empty caregiver dashboard.

Say:

> The family sees every step. The model can understand an order, but it has no
> checkout tool and cannot confirm anything.

### 0:27 to 0:43

Select **Ensaiar pedido por voz**.

Read the sample phrase:

> Silvia, quero um salmão grelhado com legumes e um suco de laranja.

### 0:43 to 1:00

Point to the items, R$6,90 delivery fee, R$66,70 total, saved address,
cash-on-delivery mode, and `Demonstração segura` label.

Say:

> Silvia builds an immutable draft and reads back the items, fee, total,
> address, and payment method. This confirmation only works for this sender,
> this price, and this draft before it expires.

### 1:00 to 1:16

Select **Confirmar pedido de demonstração** once.

Say:

> One valid confirmation permits one atomic checkout attempt. A repeat cannot
> create a second order, and failures never retry on their own.

### 1:16 to 1:30

Show `Pedido concluído` and the live audit timeline.

Say:

> This contest build uses a labelled demo restaurant, so no food was bought.
> The same deployed backend already has verified Meta webhook and ElevenLabs
> transcription paths ready for authorized credentials.

End on the safety strip.
